# singleplayer
Simplifies Minecraft.

In our lives, we are often bombarded by choices. Simple solution: remove them. You can now only click the singleplayer, options, and exit game buttons on the title screen. That is just about all this does.<br>
Breaks Modmenu (just on the title screen) as well.
