# Singleplayer
Simplifies Minecraft.

Hi! I won't be actively porting to any new versions, so if there's a version you'd like to see, open an [issue on GitHub](https://github.com/midnightdoggo19/singleplayer/issues)!

In our modern lives, we are often bombarded by choices. Simple solution: remove them. You can now only click the singleplayer, options, and exit game buttons on the title screen. That is just about all this does.<br><br>
Breaks Modmenu (just on the title screen) as well, so at least we have that.<br>
